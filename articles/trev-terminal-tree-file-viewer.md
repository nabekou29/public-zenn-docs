## つくったもの

![screenshot](/images/trev-terminal-tree-file-viewer/screenshot.png)

https://github.com/nabekou29/trev

プレビュー付きのファイルツリーを表示する TUI アプリです。完全に AI に作らせました。

## 作った理由

開発は普段 Neovim でやっているのですが、開発の拠点が Claude Code になってきて必ずしも Neovim を開く必要のないことも多いです。

最近では、プロジェクトの構成の確認、ファイルの中身の確認、手で編集したい場合などの要所で Neovim を開くようにしていました。

とはいえ、ファイルツリーを見たいだけなのに Neovim を開くのは少し大袈裟に感じていたのと、Neovim 自体は軽量でも LSPサーバーが重かったりすると複数起動するのもよくないなと思っていました。

そこで今回の開発に至りました。

## 機能紹介

以下はドキュメントからの引用です。

- **ツリービュー** — ディレクトリ構造を展開・折りたたみで閲覧
- **シンタックスハイライト付きプレビュー** — syntect による組み込みハイライト、外部ツール不要
- **画像プレビュー** — Sixel/Kitty プロトコルによるインライン画像表示
- **外部コマンドプレビュー** — カスタムコマンド（`jq`、`glow`、`dust` など）でファイルを表示
- **ファジー検索** — nucleo によるインタラクティブなファイル絞り込み
- **ファイル操作** — コピー、切り取り、貼り付け、リネーム、削除、Undo/Redo、OS クリップボード連携
- **ファイルシステム監視** — 外部からの変更を自動検知して反映
- **セッション保存** — 再起動後もツリーの状態を復元
- **Neovim 連携** — IPC サーバーモード（[trev.nvim](https://github.com/nabekou29/trev.nvim)）
- **柔軟な設定** — YAML 設定ファイル、キーバインドのカスタマイズ、JSON Schema 対応

欲しい機能を詰め込んでます。

開発時に嬉しい機能がメインですが、開発以外のシーンでも使えるようになっていると思います。

### お気に入りの機能① - Neovim との統合

Neovim から独立したものとして作りたいのと同時に、Neovim 上でも同じ体験ができるようにしたいと思っていました。

trev を起動してファイルを開くなどの操作に加えて、以下のような機能も実装しています。

- プレビューの表示に Neovim のウィンドウを使う
- 開いているファイルをツリー上で Reveal する

特に [snacks.nvim](https://github.com/folke/snacks.nvim) を使っている場合にはプレビューに画像も表示できていい感じです。

https://youtu.be/LLGrOHXINUg

### お気に入りの機能② - スマートソート

ファイルの表示順はいくつかを切り替えられるようにしていますが、デフォルトでは `smart` ソートを採用しています。

このソートは、接尾辞によるグルーピングを実現していて、テストファイルが対応する実装ファイルの直後に並ぶようになっています。

このような4つのファイルがある場合、次のように並ぶのが理想的だと思っています。

```
hoge.go
hoge_test.go
hoge_fuga.go
hoge_fuga_test.go
```

しかしながら、単純に名前順でソートすると、

```
hoge.go
hoge_fuga.go
hoge_fuga_test.go
hoge_test.go
```

このようになってしまいます。

それを `smart` ソートでは、接尾辞 `_test` を認識して、理想的な並びにしてくれます。
名前のパターンなどで自由にスタイルも設定できるので、テストファイルを暗めに表示したりするとより見やすくなります。

![smart-sort](/images/trev-terminal-tree-file-viewer/smart-sort.png)

`Piyo.tsx` `Piyo.test.tsx` のようなパターンや、数値を含むファイル名の自然数ソート (file2 < file10) も `smart` ソートに含んでいます。

もともとソート機能を柔軟に設定できるようにしようと思っていたのですが、別に自分に都合のいいやつだけ作ればいいかと開き直って `smart` ソートとして実装することにしました。

### そのほかお気に入り・こだわりの機能

- **Vim ライクなキーバインド**
  - `j/k`、`g/G`、`<C-d>/<C-u>` などの移動に加えて、`zz` などのセンタリングも実装しています。
- **OS クリップボードとの連携**
  - 今回のように記事を書いてるときなどは、画像をクリップボードから画像用のディレクトリに直接貼り付けられるのが便利でした。
- **セッションの保存**
  - ツリーの展開状態、選択しているファイル、スクロール量までを保持しているので、頻繁に閉じたり開いたりがしてもストレスが少ないと思います。
